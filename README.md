# PyCep

A Python editor that runs right in your browser. No install, works on iPad, iPhone, Mac, Windows and Android.

**Try it:** https://pycep.netlify.app

## Features
- Syntax colors and autocomplete
- Run / Stop, separate input() field
- Output and Terminal
- Multiple files, code saved automatically
- Dark and light mode
- Installable as an app (PWA)

Python runs in the browser using [Skulpt](https://skulpt.org).
